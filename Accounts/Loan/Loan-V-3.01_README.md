# সাদা কালো — লোন (নেওয়া) ম্যানেজমেন্ট সিস্টেম

**সংস্করণ:** ৩.০ | **PHP:** ৮.১+ | **ডাটাবেস:** MySQL / MariaDB
**পরীক্ষিত:** PHP 8.3 + MariaDB 10.11 — ৬৭টি অটোমেটেড টেস্ট, সব পাস

এই সিস্টেম হিসাব রাখে **আপনি কোথা থেকে কত টাকা লোন নিয়েছেন এবং
কিস্তিতে কত শোধ করছেন** — অর্থাৎ আপনি ঋণগ্রহীতা। ব্যাংক, NGO বা ব্যক্তির
কাছ থেকে নেওয়া প্রতিটি লোনের আলাদা প্রোফাইল, লেজার ও প্রিন্ট আছে।

## ২. আপনি যা যা চেয়েছেন — সব আছে

### ✅ শুধু আপনি যেসব লোন নিয়েছেন
সব হিসাব ঋণগ্রহীতার দৃষ্টিতে: **কত নিলাম / কত শোধ করতে হবে / কত শোধ
করেছি / কত বাকি / কত সুদ দিলাম।**

### ✅ কিস্তি শোধের তারিখ (due date) সিলেক্ট ও এডিট
- **নতুন লোনে:** "প্রথম কিস্তির তারিখ" বাধ্যতামূলক পিকার
- **পরে বদলানো:** প্রোফাইলে "কিস্তির তারিখ" বোতাম
- **অটো:** কিস্তি শোধ করলেই তারিখ নিজে এক ধাপ এগোয় (দৈনিক ১ দিন /
  সাপ্তাহিক ৭ দিন / মাসিক ১ মাস)
- **কিস্তি বোর্ড:** আলাদা "কিস্তি" পেজে — বকেয়া / আজকের / আগামী ৭ দিন

### ✅ কিস্তি শোধের সময় ক্যামেরা/ছবি আপলোড + কমেন্ট
- ছবি তোলা বা গ্যালারি থেকে আপলোড (`capture="environment"` — মোবাইলে
  সরাসরি ক্যামেরা খোলে)
- সাথে কমেন্ট (যেমন "বিকাশে পাঠানো")
- লেজারে রসিদের ছোট থাম্বনেইল — ক্লিক করলে বড় করে দেখা যায়
- ছবি ঐচ্ছিক — না দিলেও কিস্তি শোধ হবে

### ✅ প্রতিটি লোনের আলাদা প্রোফাইল, লেজার, প্রিন্ট
- **প্রোফাইল:** মূল টাকা, সুদের হার, প্রতি কিস্তি, মোট শোধ্য, কিস্তি
  সংখ্যা, ধরন, পরবর্তী তারিখ + **এখনো বাকি / শোধ করেছি / সুদ দিয়েছি**
- **লেজার:** প্রতিটি লেনদেন, রসিদসহ, পেজিনেশন (২০টি করে)
- **প্রিন্ট:** আলাদা প্রিন্ট-স্টেটমেন্ট — কত নিলাম, কত শোধ্য, কত বাকি,
  সুদ, সম্পূর্ণ লেজার, স্বাক্ষরের ঘর

### ✅ লেজার থেকে এডিট / ডিলিট / active-inactive
- যেকোনো এন্ট্রি এডিট (বিবরণ, টাকা, তারিখ, কমেন্ট, ছবি) বা ডিলিট
- ডিলিট/এডিটের পরে ব্যালেন্স নিজে থেকেই আবার হিসাব হয়
- লোন active ↔ inactive টগল

### ✅ সুদ যোগ হচ্ছে
লোন খোলার সময়ই মোট সুদ একটি এন্ট্রি হিসেবে বসে (দায়), তাই বাকি =
মোট শোধ্য। প্রোফাইলে "সুদ যোগ" বোতাম দিয়ে বাড়তি সুদ/লেট ফিও বসানো যায়।

### ✅ MVC স্ট্রাকচার
সম্পূর্ণ Model-View-Controller — নিচে প্রতিটি ফাইলের বর্ণনা।

## ৩. প্রতিটি ফাইলে কী আছে

### মূল

| ফাইল | কাজ |

| **`BaseModel.php`** | PDO র‍্যাপার — সব prepared statement, `transaction()`, নিরাপদ পেজিনেশন। |

| **`Views/dashboard.php`** | সারাংশ, লোন ফর্ম (লাইভ হিসাব), কিস্তি শোধ ফর্ম (ছবি+প্রিভিউ), প্রোফাইল তালিকা+বিস্তারিত, লেজার। |

- **লেজার ড্রয়ার (প্রতি প্রোফাইল আলাদা):** ডান দিক থেকে খোলে —
  বাকি/শোধ/সুদ, প্রোগ্রেস বার, সম্পূর্ণ লেজার এবং **ডকুমেন্ট/রসিদের
  ছবি পাশে** (ক্লিক করলে বড় হয়)। নিচে **রিপোর্ট/ডাউনলোড (প্রিন্ট)** ও
  **শোধ** বাটন।

### API রাউটিং (গুরুত্বপূর্ণ)
- বোর্ড লোড ও দ্রুত শোধ → `fetch_board`, `quick_pay` (Repayment মডিউল,

  কারণ পেজটি `/repayment`-এ চলে। **কোনো নতুন এন্ডপয়েন্ট লাগেনি** —

- যদি আপনার `add_payment`/`quick_pay` ফিল্ডের নাম আলাদা হয়
  (যেমন `loan_id` বনাম `id`), শুধু index.php-র FormData কী মিলিয়ে নিন।

## ২. আপনি যা যা চেয়েছেন — সব আছে

### ✅ শুধু আপনি যেসব লোন নিয়েছেন
সব হিসাব ঋণগ্রহীতার দৃষ্টিতে: **কত নিলাম / কত শোধ করতে হবে / কত শোধ
করেছি / কত বাকি / কত সুদ দিলাম।**

### ✅ কিস্তি শোধের তারিখ (due date) সিলেক্ট ও এডিট
- **নতুন লোনে:** "প্রথম কিস্তির তারিখ" বাধ্যতামূলক পিকার
- **পরে বদলানো:** প্রোফাইলে "কিস্তির তারিখ" বোতাম
- **অটো:** কিস্তি শোধ করলেই তারিখ নিজে এক ধাপ এগোয় (দৈনিক ১ দিন /
  সাপ্তাহিক ৭ দিন / মাসিক ১ মাস)
- **কিস্তি বোর্ড:** আলাদা "কিস্তি" পেজে — বকেয়া / আজকের / আগামী ৭ দিন

### ✅ কিস্তি শোধের সময় ক্যামেরা/ছবি আপলোড + কমেন্ট
- ছবি তোলা বা গ্যালারি থেকে আপলোড (`capture="environment"` — মোবাইলে
  সরাসরি ক্যামেরা খোলে)
- সাথে কমেন্ট (যেমন "বিকাশে পাঠানো")
- লেজারে রসিদের ছোট থাম্বনেইল — ক্লিক করলে বড় করে দেখা যায়
- ছবি ঐচ্ছিক — না দিলেও কিস্তি শোধ হবে

### ✅ প্রতিটি লোনের আলাদা প্রোফাইল, লেজার, প্রিন্ট
- **প্রোফাইল:** মূল টাকা, সুদের হার, প্রতি কিস্তি, মোট শোধ্য, কিস্তি
  সংখ্যা, ধরন, পরবর্তী তারিখ + **এখনো বাকি / শোধ করেছি / সুদ দিয়েছি**
- **লেজার:** প্রতিটি লেনদেন, রসিদসহ, পেজিনেশন (২০টি করে)
- **প্রিন্ট:** আলাদা প্রিন্ট-স্টেটমেন্ট — কত নিলাম, কত শোধ্য, কত বাকি,
  সুদ, সম্পূর্ণ লেজার, স্বাক্ষরের ঘর

### ✅ লেজার থেকে এডিট / ডিলিট / active-inactive
- যেকোনো এন্ট্রি এডিট (বিবরণ, টাকা, তারিখ, কমেন্ট, ছবি) বা ডিলিট
- ডিলিট/এডিটের পরে ব্যালেন্স নিজে থেকেই আবার হিসাব হয়
- লোন active ↔ inactive টগল

### ✅ সুদ যোগ হচ্ছে
লোন খোলার সময়ই মোট সুদ একটি এন্ট্রি হিসেবে বসে (দায়), তাই বাকি =
মোট শোধ্য। প্রোফাইলে "সুদ যোগ" বোতাম দিয়ে বাড়তি সুদ/লেট ফিও বসানো যায়।

### ✅ SMS নোটিফিকেশন (৩.১ — MiMSMS)
- **নতুন লোন:** খোলার সাথে নাম, টাকা, অ্যাকাউন্ট নম্বর SMS
- **কিস্তি শোধ:** শোধের পরিমাণ + বাকি টাকা কনফার্মেশন
- **কিস্তি due / বকেয়া:** নাম, অ্যাকাউন্ট, কিস্তির টাকা, পরিশোধ করুন
- **Cron:** `cron_sms_reminder.php` — প্রতিদিন আজকের + বকেয়া রিমাইন্ডার
- লোনে **মোবাইল** ফিল্ড (ঐচ্ছিক); প্রোফাইল থেকে এডিট করা যায়

### ✅ MVC স্ট্রাকচার
সম্পূর্ণ Model-View-Controller — নিচে প্রতিটি ফাইলের বর্ণনা।

## ৮. SMS সেটআপ (সংস্করণ ৩.১ — MiMSMS)

### ক্রেডেনশিয়াল

`Loan/Config/sms.env` অথবা `Loan/.env` (অথবা `/home/sadakalo/App/.env`):

```env
MIMSMS_USERNAME=আপনার@ইমেইল.com
MIMSMS_API_KEY=আপনার_API_KEY
MIMSMS_SENDER_ID=আপনার_SenderID
```

[sms.mimsms.com](https://sms.mimsms.com) → **Utility → Developer** (API Key Activate + IP হোয়াইটলিস্ট)  
→ **Utility → Sender ID** (অনুমোদিত Sender ID)

### কখন SMS যায়

| ইভেন্ট | মেথড | উদাহরণ মেসেজ |
|---|---|---|
| নতুন লোন | `sendLoanOpened` | `সাদা কালো: X থেকে ৳... লোন নেওয়া হয়েছে। অ্যাকাউন্ট: LN-...` |
| কিস্তি শোধ | `sendPaymentConfirm` | `সাদা কালো: X এ ৳... শোধ হয়েছে। এখনো বাকি: ৳...` |
| Due / বকেয়া | `sendDueReminder` | `সাদা কালো: X — আজকের কিস্তি ৳... পরিশোধ করুন।` |

### দৈনিক Cron

```bash
/usr/bin/php /home/sadakalo/public_html/Accounts/Loan/cron_sms_reminder.php
```

cPanel → Cron Jobs → প্রতিদিন সকালে চালান। শুধু **active** লোন + **mobile** আছে + due ≤ আজ।

| Action | মডিউল | কাজ |

| `send_sms_test` | Loan | টেস্ট SMS |
