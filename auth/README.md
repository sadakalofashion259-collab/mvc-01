## 🔍 ফাইলওয়াইজ লজিক

### `otp_auth.php`
1. সেশন চেক — লগইন প্রসেসে না থাকলে রিডাইরেক্ট
2. OTP ইনপুট নেয়
3. `UserModel::verifyOtp()` — ডাটাবেজে OTP মিলায়
4. সফল → সেশন সেট + ড্যাশবোর্ডে রিডাইরেক্ট
5. ব্যর্থ → এরর + কয়েকবার চেষ্টার পর কুলডাউন
6. নতুন OTP পাঠানোর অপশন (কুলডাউন টাইমার)

**কাজ:** ২-ধাপ ভেরিফিকেশন — পাসওয়ার্ডের পর OTP দিয়ে সুরক্ষিত লগইন।
